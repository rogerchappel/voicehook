# Roadmap

## Now

- Local transcript-file MVP.
- Safe default inbox capture.
- JSON output for agent review.

## Next

- Local microphone adapter behind the documented `TranscriptAdapter` boundary.
- More transcript source adapters with explicit privacy notes.
- Optional TUI/inbox review flow.
- Signed release artifacts once the package is ready for npm.

## Not planned for core

- Always-on cloud assistant behavior.
- Hidden telemetry.
- Unrestricted shell execution hooks.
